# Release Verification Evidence

Verification record for the releases from v1.0 (source commit `8e6483f`) through v1.2 (source commit `b474d69`), in chronological order. Every report here was produced by running the real application, and no result in these documents was simulated. Provider endpoints were exercised in the v1.0 release passes and in the post-rotation smoke test; the v1.2 release candidate record is deliberately a pre-deployment build record, and the v1.2 live record measures the deployed site in keyless mode, where no provider call is expected or made.
